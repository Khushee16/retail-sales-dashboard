# Retail Sales Dashboard

Interactive sales analytics dashboard — KPI cards, revenue trends, category and regional performance, top products, and RFM customer segments, with period and category filters.

- **Data & methodology:** see [retail-sales-eda](https://github.com/Khushee16/retail-sales-eda) (Python EDA notebook)
- **Live dashboard:** open `index.html` in any browser, or view it via GitHub Pages once enabled.

Built as a portfolio project for data analytics roles.
